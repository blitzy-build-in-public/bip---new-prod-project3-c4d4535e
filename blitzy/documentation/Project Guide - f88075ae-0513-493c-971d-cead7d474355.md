## G. Glossary

| Term | Meaning |
|---|---|
| Console script | A single-file program run by an interpreter and communicating only through standard streams |
| Byte-exact | Identical at the byte level, with no allowance for re-wrapping, re-encoding or trailing whitespace |
| Standard output / standard error | The two output streams; only the former carries the greeting, the latter is always empty |
| Line terminator | The single trailing `\n` that `console.log` appends, making the output 18 bytes rather than 17 |
| Deterministic | Producing the same bytes on every run, regardless of repetition or concurrency |
| Idempotent | Repeated runs accumulate nothing on their own |
| Zero-dependency boot | Running with nothing but the script present — no manifest, lockfile, `node_modules`, install or build |
| EPIPE / `SIGPIPE` | The failure a writer sees when the reader of a pipe goes away; relevant only to whatever feeds the program's stdin |
| `ENOSPC` | The write error a full device raises; the one write path not exercised during validation |
| Mandated absence | An artefact the specification forbids, whose absence is the required state rather than a gap |
